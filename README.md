## Installation and Setup
Just clone the repo and execute the server.py with python3 ,Here's a one liner command 
```shell
git clone https://github.com/rashmina-a/fly-brain-viz.git && cd fly-brain-viz && python3 server.py
```
You can use this command on powershell or terminal in linux or mac ,
